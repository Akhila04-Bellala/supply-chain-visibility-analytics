
# Supply Chain Visibility System with Optimization Analytics

### An Interactive Power BI Analytics Project

##  Project Overview

The Supply Chain Visibility System with Optimization Analytics is a data analytics project developed using Microsoft Power BI.

The project focuses on analyzing supply chain operations through interactive dashboards, helping users understand inventory performance, delivery efficiency, supplier reliability, transportation costs, and warehouse operations.

The goal is to transform raw supply chain data into meaningful insights that support better operational decisions.

---

##  Project Objectives

- Monitor inventory levels and inventory performance.
- Analyze delivery performance and delays.
- Evaluate supplier reliability.
- Understand transportation costs and route performance.
- Analyze warehouse efficiency.
- Identify trends and opportunities for operational improvement.
- Present insights through interactive Power BI dashboards.

## DAX Measures

The project uses DAX measures in Power BI to calculate key supply chain performance indicators.

- Total Orders
- Total Revenue
- Average Delivery Time
- On-Time Delivery Percentage
- Total Transportation Cost
- Average Inventory

These measures support inventory, delivery, and transportation performance analysis.
